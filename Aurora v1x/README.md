## デザイン方針

- Aurora v1の黄緑・ターコイズの髪、紫の瞳、親しみやすい印象を維持する
- 白、氷色、水色、黒を中心に、空・オーロラ・星をモチーフとする
- 既存の `Parker Set EC-Sky` の衣装構造、テクスチャおよび装飾を使用しない
- VRoid Studioの標準衣装メッシュとオリジナルテクスチャでの再現を想定する

## 衣装構成

### 初期コンセプト

- フードではなく左右に分かれたハイカラーを持つ、白いショート丈ストームシェル
- 非対称の斜め開閉と、深い黒のサイドパネル
- 氷や夜空を思わせる半透明調のグラデーションヨーク
- オーロラの流線を抽象化した袖のライン
- 小型の幾何学的な北極星モチーフの留め具
- 黒を基調とした非対称レイヤードスコートと氷色の差し込みパネル
- 控えめな星座模様の黒いレギンス
- 白と黒を基調にターコイズのソールを加えたアンクルスニーカー

### カジュアル案A：City Casual

- オフホワイトのライトジップジャケットとアイスブルーのTシャツ
- 黒いサイドパネルに、細いターコイズの曲線を一点だけ使用
- 黒いショートパンツ、無地レギンス、ローカットスニーカー
- カフェや買い物などの日常に馴染む、親しみやすい街着

### カジュアル案B：Sporty Casual

- 白とアイスブルーのシンプルなカラーブロックトラックジャケット
- 袖に最小限のターコイズライン
- 黒いプリーツスコート、無地レギンス、ランニングスニーカー
- VRoidの標準衣装構造へ比較的落とし込みやすいスポーティな日常着

### カジュアル案C：Soft Layered Casual

- オフホワイトのゆったりしたシャツジャケットと黒いモックネックトップス
- アイスブルーのパッチポケットと折り返しカフス
- 黒いラップ風スコート、無地レギンス、レースアップシューズ
- 髪色を主役にできる、落ち着いたクリエイティブ系の日常着

### ワードローブ案D：Urban Utility

- チャコールのショート丈フィールドジャケットとクリーム色のTシャツ
- スレート色のテーパードカーゴパンツとローカットスニーカー
- ターコイズはステッチと小さな引き手だけに限定
- 日常的で少し中性的な、パンツスタイルの街着

### ワードローブ案E：Soft Knit Layering

- オートミール色のゆったりしたカーディガンと白いバンドカラーブラウス
- チャコールのキュロット、濃色タイツ、控えめなローファー
- アイスブルーの縁取りと、瞳に合わせた小さな紫のアクセント
- 優しく親しみやすい、秋冬向けのニットレイヤード

### ワードローブ案F：Casual Layered Dress

- 深いネイビーのAラインチュニックワンピースとオフホワイトのTシャツ
- 片側だけにターコイズからブルーのカラーブロックを配置
- クロップドレギンスとキャンバスハイカットスニーカー
- 腰巻きシャツも組み合わせられる、軽快な春夏の日常着
