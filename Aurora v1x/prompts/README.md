# Aurora v1x Image Generation Prompts

Aurora v1xの衣装コンセプト画像を生成するために使用したプロンプトを保存しています。

## 生成方式

- OpenAIの組み込み画像生成を使用
- Aurora v1の画像は、顔、体型、髪型、髪色、瞳などのキャラクター同一性の参照として使用
- 初期コンセプト画像は、カジュアル3案で配色を参照するために使用
- 生成画像は完成したVRoidモデルやテクスチャではなく、衣装設計のためのコンセプト

- [`casual-A-city.md`](./casual-A-city.md)：街着案
- [`casual-B-sporty.md`](./casual-B-sporty.md)：スポーティ案
