# Aurora v2

Aurora v2のデザインおよび制作物を管理する作業ディレクトリです。

## 現在の成果物

- `Aurora-v2-outfit-concept.png`：衣装デザインの初期コンセプト

この画像は、Aurora v1をキャラクター同一性の参照として使用し、AI画像生成によって
制作したコンセプトです。VRoid用の完成モデルや完成テクスチャではありません。

## デザイン方針

- Aurora v1の黄緑・ターコイズの髪、紫の瞳、親しみやすい印象を維持する
- 白、氷色、水色、黒を中心に、空・オーロラ・星をモチーフとする
- 既存の `Parker Set EC-Sky` の衣装構造、テクスチャおよび装飾を使用しない
- VRoid Studioの標準衣装メッシュとオリジナルテクスチャでの再現を想定する

## 衣装構成

- フードではなく左右に分かれたハイカラーを持つ、白いショート丈ストームシェル
- 非対称の斜め開閉と、深い黒のサイドパネル
- 氷や夜空を思わせる半透明調のグラデーションヨーク
- オーロラの流線を抽象化した袖のライン
- 小型の幾何学的な北極星モチーフの留め具
- 黒を基調とした非対称レイヤードスコートと氷色の差し込みパネル
- 控えめな星座模様の黒いレギンス
- 白と黒を基調にターコイズのソールを加えたアンクルスニーカー

## 次の工程

1. 衣装構造と配色のレビュー
2. VRoid Studioで使用する衣装テンプレートの決定
3. 前面・背面・袖・ボトムス・靴のテクスチャ設計
4. VRoid上での試作と位置合わせ
5. 正式な三面図と表情資料の作成
