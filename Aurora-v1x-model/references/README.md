## 衣装の要素

- オフホワイトのゆったりしたシャツジャケット
- 黒いモックネックトップス
- アイスブルーのパッチポケットと折り返しカフス
- 黒いラップ風ボトムスとアイスブルーの差し込みパネル
- 無地の黒いレギンス
- 黒いレースアップシューズ

コンセプト画像は形状と配色の参考です。画像内の陰影をそのままテクスチャへ焼き込まず、
VRoidのシェーダーで自然に立体感が出るよう、ベースカラー、縫い目、素材表現を分けます。
